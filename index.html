1. Termux යනු කුමක්ද?

Termux යනු Android මෙහෙයුම් පද්ධතිය සඳහා ඇති **Linux Terminal Emulator** එකකි. Root කිරීමකින් තොරව Linux පරිසරයක් භාවිතා කිරීමටත්, Python, C++, Node.js, Git වැනි විවිධ Tools සහ Programming Languages ධාවනය කිරීමටත් මෙයින් හැකියාව ලැබේ.

2. මූලික සැකසුම් (Basic Setup)

Termux ස්ථාපනය කළ පසු ප්‍රථමයෙන්ම Packages යාවත්කාලීන (Update) කරගත යුතුය. ඒ සඳහා පහත Command එක ලබා දෙන්න:

pkg update && pkg upgrade -y

3. නිතර භාවිත වන මූලික Commands

Command විස්තරය (Description)
pwd ඔබ දැනට සිටින Folder එක (Present Working Directory) පෙන්වයි.
ls Folder එක ඇතුලේ ඇති Files සහ Folders ලැයිස්තුව පෙන්වයි.
cd [folder_name] වෙනත් Folder එකක් ඇතුලට යාමට භාවිතා කරයි.
clear Terminal Screen එක Clean කරයි.

4. Storage Permission ලබා ගැනීම

ඔබගේ Phone එකේ Internal Storage එකේ ඇති Files වලට Access කිරීමට පහත Command එක ගසා Permission ලබා දෙන්න:

termux-setup-storage
